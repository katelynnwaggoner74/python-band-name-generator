# 🎸 Band Name Generator

A beginner Python project that generates a band name based on user input.

## 📖 About the Project

The Band Name Generator asks the user for the city they grew up in and the name of a pet. It then combines the two answers to create a possible band name.

I completed this project while working through the **100 Days of Code: The Complete Python Pro Bootcamp**. This project gave me hands-on practice with some of the basic building blocks of Python.

## 🛠️ Skills Practiced

- Python
- Variables
- User input with `input()`
- Displaying output with `print()`
- Strings
- String concatenation

## 💻 How It Works

The program:

1. Welcomes the user to the Band Name Generator.
2. Asks which city the user grew up in.
3. Asks for the name of a pet.
4. Combines the two responses to generate a band name.

## ▶️ How to Run

Make sure Python is installed, then run:

`python band_name_generator.py`

Follow the prompts in the terminal to generate your band name.
